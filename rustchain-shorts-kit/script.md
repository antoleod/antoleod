# Script — “Your Old Computer Has an Advantage”

**Target:** 50–58 seconds at ~135–150 wpm.

**0:00–0:06 — Hook**  
What if an old computer could be more valuable to a blockchain *because* it is old?

**0:06–0:16**  
RustChain calls the idea Proof of Antiquity. Before a miner earns rewards, it submits hardware attestation so the network can check that the machine is real physical hardware.

**0:16–0:29**  
The project’s attestation design measures physical signals such as clock drift, cache timing, SIMD behavior, thermal entropy, instruction jitter, and anti-hypervisor heuristics.

**0:29–0:40**  
Its newer Proof of Physical AI specification expands that idea to seven independent fingerprint channels, plus server-side verification, fleet detection, and anti-emulation checks.

**0:40–0:51**  
That changes the incentive: instead of treating old silicon as e-waste, the network can assign antiquity-based reward weight to authenticated hardware.

**0:51–0:57 — Close**  
Proof of Work values energy. Proof of Storage values disk space. RustChain is experimenting with something different: verifiable physical history.
