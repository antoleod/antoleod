# RustChain Shorts Kit — “Your Old Computer Has an Advantage”

Submission package for Scottcjn/rustchain-bounties#16601, Type C (Shorts / clip kit).

**Format:** vertical short, 9:16, target 50–58 seconds.  
**Hook:** “What if an old computer could be more valuable to a blockchain *because* it is old?”

This package is designed so a publisher can produce the clip without additional research. It contains:

- `script.md` — timed narration, under 60 seconds
- `storyboard.md` — exact 9:16 capture/graphic instructions
- `metadata.md` — title, description, tags, caption text
- `SOURCES.md` — claim-by-claim source map pinned to public RustChain documentation

No third-party footage, logos, music, or copyrighted media are required. The recommended visuals are original text/diagram panels and terminal-style captures generated from the public source material. The script and storyboard are original and may be published by Elyan Labs with attribution to `antoleod`.
